Cockerel screen gallery DEV ONLY

Every major screen state, side by side. Scroll horizontally to compare. Each card is a real, isolated instance of the app (an iframe) pre-loaded onto that one screen with fixture data — Refresh restarts its entrance animation and any timer, Theme cycles dark/light per card, and the Preview language dropdown above switches every card at once between Norwegian and English fixture content. Feedback typed below a card is logged server-side with its screen id, theme, and language, timestamped — ask Claude Code to "check the gallery feedback log" to work through it. Not reachable when the server is deployed with DEV_TOOLS=0.
